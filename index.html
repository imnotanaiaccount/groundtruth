    About this data

    What am I actually looking at?

    groundtruth queries OpenStreetMap for points tagged as automated license plate reader (ALPR) surveillance equipment, including devices tagged as operated by Flock Safety. This data comes from volunteers who physically document camera locations and add them to the shared, public map — the same map that also runs your GPS app.

    Is this a complete picture?

    No. Camera vendors don't publish install locations, so no source — this one included — can be exhaustive. A "no results" reading means nothing is documented yet, not that nothing is there. Coverage is strongest in cities with an active mapping community and thinner elsewhere.

    Why does "recently added" matter?

    It reflects when the map entry itself was created or last edited — usually because someone spotted and logged a device. It's a reasonable proxy for recent activity in an area, but an edit can also just be someone correcting an existing entry.

    Can I add a camera I've found?

    Yes — this tool reads from OpenStreetMap, so anyone can contribute. Tag the point man_made=surveillance, surveillance:type=ALPR, and an operator if known, using iD or any OSM editor.

    Is this legal / what's the point?

    Mapping publicly visible infrastructure from public data is the same activity as any street-level map. groundtruth exists so people can understand what's tracking vehicle movement on their own block — nothing here identifies who owns a plate or where any specific vehicle has been.
